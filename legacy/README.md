# Legacy snapshot: ожидается

На момент аудита исходники не найдены в рабочей папке. Никакой новый файл не выдаётся за исторический код.

Для завершения снимка нужны:

- n8n workflow export → `n8n/workflow.json`;
- точный код Parse Structure → `n8n/parse-structure.js`;
- рабочая версия Val Town → `valtown/main.ts`;
- обезличенные вход/выход Gemini, вход renderer и эталонная PPTX с версиями PptxGenJS/runtime.

Перед импортом проверить токены, Authorization headers, webhook secrets, credentials и персональные данные. Оригиналы с секретами хранить вне Git. Сохранить очищенную копию без изменения логики; в manifest указать происхождение, дату экспорта, версии, SHA-256 сохранённых файлов и список redactions. Snapshot не считается byte-identical оригиналу, если он очищен. Не исполнять импортированный workflow во время аудита.

После получения сравнить реальные поля с проектом контракта. Различия документировать; не добавлять молчаливые aliases. Git-коммит snapshot отделить от будущего refactor.
